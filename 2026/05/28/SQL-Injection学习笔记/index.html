1. SQL Injection简介

SQL Injection（SQL注入）是一种常见的Web安全漏洞。

攻击者通过构造恶意SQL语句，影响后台数据库查询逻辑，从而实现：

  • 绕过身份认证
  • 获取数据库信息
  • 获取用户数据
  • 修改数据库内容
  • 甚至控制服务器

本次实验基于 DVWA（Damn Vulnerable Web Application） 靶场完成。

实验环境：

  • Windows 11
  • PHPStudy
  • Apache
  • MySQL
  • DVWA

8. SQL Injection (Blind) 盲注

Blind SQL Injection（盲注）与普通 SQL 注入不同：

  • 页面不会直接返回数据库查询结果
  • 攻击者只能通过“页面是否存在变化”判断 SQL 是否执行成功
  • 通常依赖：
    • 页面回显差异
    • 时间延迟
    • 布尔判断

DVWA 中的 Blind 模块是学习盲注最经典的实验环境之一。

8.8 Blind SQL Injection 总结

Blind SQL Injection 虽然无法直接显示数据，

但攻击者仍然可以通过：

  • 布尔判断
  • 字符猜解
  • 时间延迟

一步步获取：

  • 数据库名
  • 表名
  • 字段名
  • 用户数据

因此：

开发中应使用：

  • 预编译语句（Prepared Statement）
  • 参数化查询
  • 输入过滤
  • 最小权限原则

防止 SQL 注入漏洞出现。

总结

本次学习基于 DVWA 靶场完成了 SQL Injection 与 Blind SQL Injection 实验。

学习内容包括：

  • SQL 注入原理
  • 判断注入点
  • 字段数判断
  • UNION 联合查询
  • 获取数据库信息
  • 获取用户数据
  • Blind SQL Injection
  • 时间盲注

通过实验可以发现：

SQL 注入漏洞危害极大，

攻击者甚至能够直接读取数据库中的敏感信息。

因此 Web 开发中必须做好：

  • 参数过滤
  • 输入校验
  • 预编译查询
  • 权限控制

从根源上避免 SQL 注入漏洞。
